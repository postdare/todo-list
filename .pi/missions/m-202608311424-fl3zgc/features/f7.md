# Feature f7 — Add new todo input flow

## Summary

Pressing `n` enters input mode (focused `textinput` with a 新任务标题 prompt).
Typing fills the input; Enter trims, saves a new todo with status 未开始 via
`store.Add`, jumps to the 未开始 tab, and selects the new item; Esc cancels.
The todo is persisted immediately and appears in the list.
