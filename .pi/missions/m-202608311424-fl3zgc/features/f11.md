# Feature f11 — Help footer with keybindings

## Summary

Persistent footer shows the keybindings: `↑/↓ 选择 · ←/→ 切换标签 · n 新建 ·
Space 完成/重开 · i 进行中 · q 退出`. While adding a todo the footer switches to
`Enter 保存 · Esc 取消`. The footer is rendered dim and unobtrusive.

## Tests

- PTY tests assert `q 退出` appears in list mode and that the footer switches
  back after committing a todo.
