# Feature f10 — Lipgloss styling and layout

## Summary

Cohesive color scheme across the UI: cyan-accented title and active tab,
segmented tab bar, inverted selected row, dimmed footer and empty state, red
error line for storage failures. Layout is width-aware: long titles truncate
with an ellipsis (width counted in terminal cells via runewidth) and narrow
terminals render without crashing.

## Tests

- PTY tests render at 100x30 and assert styled rows (e.g. `▸ 写周报`,
  `▸ ✓ 写周报`).
