# Feature f12 — Integration smoke tests

## Summary

End-to-end tests drive the real binary in a PTY (via `github.com/creack/pty`,
with a terminal emulator that answers bubbletea/termenv's startup OSC-11/DA
queries):

- `TestBinaryLaunchesTUIAndQuits` — launches, renders three tabs, `q` exits 0.
- `TestAddTodoAndPersist` — adds a CJK todo through the UI, quits, asserts the
  JSON file contains a human-readable record with id/title/status/created_at.
- `TestStatusFlowAndPersistence` — adds two todos, marks in-progress,
  completes, reopens, then verifies final JSON.

Programmatic model tests live in `internal/tui/tui_test.go`. Smoke commands are
documented in `README.md`. `go test ./...` passes.
