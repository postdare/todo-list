# Feature f6 — Keyboard navigation

## Summary

`handleKey` implements: ↑/↓ move selection within the active tab (clamped to
bounds); ←/→ switch tabs and reset selection; `q`/Ctrl+C quit. Handles
batched `KeyRunes` messages (multiple printable runes delivered in one
message) so scripted/pasted input is never dropped, and a lone space
(`KeySpace`) toggles completion. Empty tabs never crash.

## Tests

- `internal/tui/tui_test.go::TestNavigationSelection` — bounds clamping and
  tab-switch selection reset.
- `internal/tui/tui_test.go::TestQuitKeys` — `q` and Ctrl+C quit.
