# Feature f5 — Render tabs and filtered todo list

## Summary

`View()` renders a lipgloss tab bar (未开始 / 进行中 / 已完成, active tab
highlighted), the todo list filtered by the active tab with a selection
indicator (▸) on the selected row, an empty-state hint (暂无任务) for empty
tabs, and a help footer. Long titles are truncated width-aware (CJK-safe) so
narrow terminals never crash.

## Tests

- `internal/tui/tui_test.go::TestEmptyTabRendersGracefully` — empty tab renders
  empty-state hint and tolerates navigation/space/i.
- PTY tests assert tab labels and selected-row rendering.
