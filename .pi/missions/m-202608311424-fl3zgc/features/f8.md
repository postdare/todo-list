# Feature f8 — Space toggles completion

## Summary

Pressing Space on a selected todo whose status is not 已完成 changes it to
已完成; pressing Space on a 已完成 todo changes it back to 未开始. The change is
persisted immediately via `store.Update` and the list re-renders with the item
in the correct tab (✓ prefix shown in the 已完成 tab).

## Tests

- `internal/tui/tui_test.go::TestSpaceTogglesDone` — both directions, plus
  no-crash on empty tabs.
- `cmd/todo-list/main_test.go::TestStatusFlowAndPersistence` — full PTY flow.
