# Feature f4 — Bubble Tea app scaffold

## Summary

Implemented the full Bubble Tea application in `internal/tui/tui.go`: `Model`
with state for active tab, selected index, todos, input mode, and a
`textinput` buffer; `Init`, `Update`, `View`. Wired the entry point in
`cmd/todo-list/main.go` to `tea.NewProgram(..., tea.WithAltScreen())` with a
JSON-backed store from `storage.NewXDGStorage()`. The app starts, renders, and
exits cleanly on `q`/Ctrl+C.

## Tests

- `cmd/todo-list/main_test.go::TestBinaryLaunchesTUIAndQuits` — PTY test:
  launches the real binary, asserts the three tab labels render, sends `q`,
  asserts exit code 0.
