# Feature f9 — Mark in-progress with `i`

## Summary

Pressing `i` on the selected todo sets its status to 进行中 and persists it
immediately. The todo moves to the 进行中 tab and selection clamps gracefully
when the item leaves the current tab.

## Tests

- `internal/tui/tui_test.go::TestMarkInProgress`.
- `cmd/todo-list/main_test.go::TestStatusFlowAndPersistence` — PTY flow
  exercises `i` end-to-end and verifies final JSON statuses.
